# MediGuard AI 🏥⚡
**AI-Powered Smart Emergency & Hospital Response System**

MediGuard AI predicts patient emergency risk, performs AI-assisted triage, recommends hospital/bed allocation, and gives doctors an explainable real-time dashboard for faster emergency response.

## Tech Stack
- **AI/ML:** Python, scikit-learn, SHAP (explainability)
- **Backend:** FastAPI, PostgreSQL, WebSocket
- **Frontend:** React, Chart.js, Tailwind CSS
- **Deployment:** Docker
